# Optymalizacja Procesu Biznesowego metodą Makigami & Lean Management

## O projekcie
Projekt obejmuje kompleksową analizę oraz optymalizację procesu harmonogramowania czasu pracy personelu w obiekcie kinowym. Celem projektu było zidentyfikowanie wąskich gardeł, wyeliminowanie marnotrawstwa czasowego oraz skrócenie całkowitego czasu trwania procesu (Lead Time).
## Zakres analizy i wykorzystane metodologie
*   **Mapowanie Makigami (Stan AS-IS):** Szczegółowe odtworzenie i audyt obecnego przebiegu procesu z podziałem na czynności, odpowiedzialne osoby/działy oraz przepływ informacji.
*   **Analiza VA/NVA (Value Added vs. Non-Value Added):** Skonstruowanie bilansu czasu. Identyfikacja strat wykazała, że czynności niedodające wartości (NVA) stanowią aż **47,6%** całkowitego czasu procesu (191 minut marnotrawstwa na każde 401 minut pracy).
*   **Definiowanie celów SMART:** Wyznaczenie mierzalnych kierunków zmian i optymalizacji działań operacyjnych.
*   **Projektowanie stanu docelowego (Stan TO-BE):** Stworzenie nowej mapy procesu eliminującej zidentyfikowane luki biznesowe oraz zaprojektowanie nowych mierników efektywności (KPI / Mierniki).

## Narzędzia
*   MS Excel (Zaawansowana strukturyzacja danych, kalkulacje czasu procesu, wizualizacja mapy)
*   Metodologia Lean Management / Makigami Process Mapping
